# Image Keeper: working rules

- After every completed and tested change, make one commit with a message summarising what changed and why.
- Before starting a change, check that the working tree is clean (`git status`). If it isn't, report it and ask the user.
- Push after each commit.
- Do not modify NoteTaker. Test in throwaway Chrome profiles. Do not write to the user's real folders.
- Use git for backups. Do not keep backup copies in temp folders.
